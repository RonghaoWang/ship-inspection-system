# 模块：焊缝外观缺陷检测

## 一、场景与目标

**应用阶段**：船舶建造期 · 小组立车间焊缝人工目视复检替代

船体焊缝质量决定船舶交付。传统人工目视 + 记录方式效率低、易漏检、可追溯性差；X 射线抽检成本高、覆盖率有限。本模块面向小组立焊缝外观缺陷（对标 CB/T 3802-2019 五类缺陷：气孔、渣、裂纹、咬边、未熔合），提供图像 → 缺陷位置 + 分类的自动化能力。

## 二、方法

- **主干**：改进 YOLOv8
- **关键创新**：
  - **WCM 小波卷积模块（Wavelet Convolution Module）**：通过离散小波变换 DWT / 逆变换 IDWT 提取多尺度特征，专门增强小目标缺陷（气孔、渣）的检测精度
  - **小尺度检测头**：针对气孔、渣等亚毫米级缺陷
  - **SIoU 损失**：提升缺陷边缘感知
- **辅助策略**：
  - 大图切片推理（overlap ratio 可调）
  - CLAHE + LAB 空间自适应亮度归一化，处理焊缝反光与阴影

## 三、数据

- **数据来源**：华南某大型船厂小组立车间实拍
- **数据规模**：详见配套论文
- **标注规范**：对标船舶焊缝质量国家标准 CB/T 3802-2019

## 五、快速上手

```bash
# 安装依赖
pip install ultralytics opencv-python numpy


# 完整推理（区域检测 + 缺陷检测两阶段）
python infer.py
```

推理结果输出至 `result.json`。
