# 模块：涂层损坏面积量算

## 一、场景与目标

**应用阶段**：船舶运营期 · 坞修检修

船体涂层是运营期腐蚀防护的第一道屏障。运营 20~30 年反复坞修，涂层损坏面积估算长期依赖人工画格 + 目测，误差大、工程量清单不可靠、影响坞修报价与工期。本模块面向坞修现场，实现 RGB-D 相机扫描 → 涂层损坏区域自动分割 → 真实物理面积（m²）量算。

## 二、方法（三阶段架构）

### 阶段 1：RGB-D 图像采集与优化

- **采集**：主动式 RGB-D 相机（Orbbec 系列）
- **优化算法**：LingBot-Depth 图像优化算法
  - 建模主动式 RGB-D 图像质量退化特性
  - 图像与深度信息联合优化，为下游分割提供高质量输入

### 阶段 2：涂层锈蚀语义分割

- **主干**：SegFormer（Transformer-based 语义分割）
- **关键改进**：
  - **迁移学习**：船体锈蚀数据集下达到 mIoU 65.36%（超过 SegFormer 基线约 8%）
  - **深度信息融合**：将深度信息接入分割流程，提升边界与遮挡区域分割精度

### 阶段 3：真实面积几何计算

从像素掩膜 → 真实物理面积（m²）的完整几何链：

- **针孔相机模型**：像素坐标 → 相机坐标
- **RANSAC 平面拟合**：从损坏区域点云稳健拟合局部平面
- **SVD 求投影**：将三维点云投影至最佳拟合平面
- **凸包提取**：计算投影后的凸包面积作为真实物理面积

## 三、数据

- **数据集**：自建船体涂层锈蚀 RGB-D 数据集
- **采集环境**：真实船体外板 / 坞修现场模拟

## 四、指标

| 指标 | 数值 |
|---|---|
| 分割 mIoU | **65.36%** |
| 相对 SegFormer 基线提升 | **+8%** |
| 推理速率（RGB-D 全链路） | **13 - 18 FPS** |
| RK3588 NPU 部署精度损失 | 仅 2.65% |
| RK3588 NPU 推理速率提升 | +15.79% |

## 五、快速上手

```bash
# 安装依赖
pip install -r requirements.txt

# 启动 GUI（实时 RGB-D 采集 + 分割 + 面积可视化）
python main_gui.py
1.实时检测：点击开始
2.导入测试图像检测：点击导入，进行测试图像的导入，测试图像的深度图也要放于相同文件夹中，并点击加载语义分割模型，并启动语义分割模型，即可实现分割与面积可视化



## 六、目录

```
coating_damage/

```

## 七、多后端推理

模块通过 `src/utils/model_loader.py` 提供统一模型加载接口，支持三种后端：

| 后端 | 用途 | 典型硬件 |
|---|---|---|
| ONNX Runtime | 服务端 / PC | CPU / CUDA |
| RKNN | 边缘端 | 瑞芯微 RK3588 NPU |
| MDM | 深度估计（可选） | 需 HuggingFace 权重 |
